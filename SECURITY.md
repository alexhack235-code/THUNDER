# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The THUNDER team takes the security of our defensive framework and our users seriously.

If you discover a security vulnerability, flaw, or potential evasion in THUNDER, please report it responsibly:

1. **Do not open public GitHub issues** for security vulnerabilities.
2. Email your findings and proof-of-concept to the security team or maintainers at: `security@nexo-tech.dev`.
3. Provide detailed steps to reproduce the issue, including operating system, PowerShell / bash version, and sample payloads if applicable.
4. You will receive an acknowledgment within 48 hours, followed by regular updates until a patch is released.

Thank you for helping keep THUNDER safe and effective!
